# 回声 Echo · AI 求职助手

把岗位采集、匹配判断、话术生成、聊天跟进与复盘连成一条可检查的工作流。浏览器扩展 v1.0.0，当前主要适配猎聘。由产品负责人定义需求、设计交互和评测，与 AI 协作开发。

## 使用流程

需求 → 采集 → 判断 → 候选 → 生成/回复 → 记录 → 总结。

- 采集收藏、搜索、应聘记录和聊天；同平台岗位标识或规范化链接匹配已有记录。
- 保留原岗位多维评分，并分别解释“我符合岗位吗”“岗位符合我吗”。
- 岗位可用性、用户决策、招聘进度独立保存。生成或复制不等于已投递。
- 聊天识别双方消息与系统提示，依据可靠身份、时间和角色决定下一步；不确定项交由用户确认。
- 保留分析、图表、求职画像、支持性文案和历史。

## AI 内容生成工作流

~~~mermaid
flowchart LR
  A[JD / 真实档案 / 相关上下文] --> B[Strategy: 要求与经历配对]
  B --> C[Generator: 自然表达匹配亮点]
  C --> D[Evaluator: 匹配 / 个性化 / 真实性 / 简洁 / 自然度]
  D --> E{需要修改?}
  E -->|是| F[一次修改并重新检查]
  E -->|否| G[写回原岗位 / 用户核对]
  F --> G
~~~

保留策略、评估和错误信息，使问题可以定位到具体阶段；允许忠实转译，不编造经历或承诺。具体流程见 workflow.js 与 background.js。质量改进必须靠评测验证，不能用调用次数证明。[评测与迭代](CASE-STUDY.md)。

## 安装与首次使用

1. 下载源码并解压到固定目录，在 Chrome/Edge 扩展管理中开启开发者模式，加载包含 manifest.json 的目录。
2. 跟随七步引导：欢迎 → DeepSeek Key → 外部 AI 授权 → 档案 → 可选目标 → 保存首岗 → 生成首条话术。
3. 没有 Key 可暂用本地保存、查看和编辑功能；模型功能须配置 Key 并主动授权。
4. 设置页顶部可“重新体验新手引导”；已有用户升级不强制弹出。更新时覆盖原目录并重新加载，不卸载扩展。

生成需要你自己的 DeepSeek API，服务可用性及费用以实际供应商为准。此版本未作公开环境的全面跨浏览器验收。

## 隐私与边界

业务数据与设置默认保存在本地。主动使用 AI 时，必要的 JD、档案或聊天会发送给 DeepSeek；OCR 另需百度授权。本机同步为可选功能，独立本机服务未随本仓库提供。[详细说明](PRIVACY.md)。
不自动投递或发送，不提供账号/支付系统；联网补充取证当前暂停。页面结构变化、登录失效及未知消息仍可能需要人工处理。

## 开发与验证

不需要构建框架，运行文件为原生 JavaScript/HTML/CSS。Node.js 运行 npm test 执行6个可公开的合成数据回归检查，无 API Key、无模型费用。
内部1.0基线46项自动检查通过；这不是46项真实猎聘验收。公开测试覆盖工作流真实性修改、存储校验、生成结果、合并及无Key采集。[验收说明](ACCEPTANCE.md)。

主要文件：agent-page.js/content.js 抓取；agent-tasks.js 后台队列及统一保存；agent-core.js 状态规则；workflow.js 生成工作流；app.js/agent-ui.js 界面；onboarding.js 新手引导；sync-data.js 同步字段。
