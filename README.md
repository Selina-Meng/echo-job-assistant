# 回声 Echo · AI 求职助手

**把散落的岗位、沟通和下一步，整理成一条清楚的求职路线。**

适合正在使用猎聘、需要反复整理岗位和准备沟通的求职者。运行于电脑端 Chrome / Edge；不用注册 Echo 账号。

[下载安装包](https://github.com/Selina-Meng/echo-job-assistant/releases/download/v1.0.0/echo-ai-job-assistant-v1.0.0.zip) · [查看版本说明](https://github.com/Selina-Meng/echo-job-assistant/releases/tag/v1.0.0)

## 它能帮你解决什么？

| 你遇到的问题 | Echo 帮你做什么 |
|---|---|
| 收藏很多岗位，却记不清看过哪些 | 采集岗位并合并同一岗位的来源，保留你的备注与决定 |
| 不知道该优先考虑哪一个 | 同时看“我符合岗位吗”和“岗位符合我吗”，给出匹配依据 |
| 每次打招呼都要重新组织语言 | 从真实经历中提炼相关亮点，生成后检查，供你编辑使用 |
| 聊天太多，容易忘记谁该回复 | 整理消息与等待状态，把待处理事项集中起来 |
| 感觉一直在忙，却看不到进展 | 用记录、图表、画像和总结回顾已做的事 |

## 第一次使用：约定好工具怎样帮助你

### 1. 安装到浏览器

1. 下载上方 ZIP 安装包，**完整解压到一个固定文件夹**，不要直接打开 ZIP 使用。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 manifest.json 的文件夹。在浏览器扩展菜单中打开“回声 Echo”。

这是手动加载的扩展，目前不是应用商店安装。升级时覆盖原目录并重新加载，**不要卸载或换目录**，以保留原数据。

### 2. 跟随新手引导

欢迎 → 填写 DeepSeek API Key → 勾选数据授权 → 填写真实能力档案 → 设置求职目标（可跳过）→ 保存第一个岗位 → 生成第一条招呼语。

- **没有 Key 也能开始：**选择“暂用本地功能”，先保存岗位、查看记录和手动编辑。
- **需要 AI 时：**到 [DeepSeek 平台](https://platform.deepseek.com/api_keys) 获取自己的 API Key，在引导或设置中填写。API 用量由 DeepSeek 计费，Echo 不代收。
- **档案写什么：**你做过的工作、负责的事情、技能和能核对的成果。不确定的信息留空。
- **目标怎么生效：**先写自然语言需求，再在“需求”页回答选择题、确认硬软标签。
- **想重来一次：**设置页顶部点击“重新体验新手引导”，不会删除已有记录。

### 3. 完成你的第一轮求职整理

| 操作 | 你会看到什么 | 下一步 |
|---|---|---|
| 在猎聘打开岗位详情，进入“采集”，抓取当前岗位 | 岗位保存到记录，按状态进入判断 | 查看资料与匹配依据 |
| 在“判断”选择加入候选或暂不考虑 | 你的决定同步到记录 | 候选岗位可进入话术生成 |
| 为候选岗位准备话术 | 经过策略、生成、检验的草稿 | 核对事实、修改，再复制使用 |
| 打开猎聘聊天并抓取 | 沟通进展及下一步；不确定项需确认 | 回复、跟进或继续等待 |
| 打开“记录”和“总结” | 岗位历史、行动概览与复盘 | 决定下一轮重点 |

**你始终决定是否发送。Echo 不自动投递、不自动发消息；生成或复制不等于已投递。**

## 话术为什么不只是点一下生成？

![内容生成示意：资料、策略、草稿、检查、人工确认](docs/content-workflow.svg)

先把岗位要求和你的真实经历对应起来，再起草、检查并按需修改。你可以看到依据与检查结果。模型仍可能出错，使用前请核对；步骤更多并不保证文案更好。[查看我们的测试与反思](CASE-STUDY.md)。

## 遇到问题时

| 情况 | 可以怎么做 |
|---|---|
| 看不到新手引导 | 设置 → 重新体验新手引导 |
| 提示配置 Key / 授权 | 设置 → AI与授权；未授权时仍可用本地功能 |
| 当前岗位抓不到 | 确认已登录猎聘并打开详情页；按错误提示重新读取或补充资料 |
| 聊天进入“需要确认” | 核对联系人、岗位、发言方或时间；不要用猜测替代缺失信息 |
| AI 分析失败 | 保留已有资料与草稿，检查配置和错误原因后重试 |
| 准备升级或换浏览器 | 先在设置中导出备份；备份含私人资料，请自行保管 |

## 数据、许可与当前限制

数据默认保存在本地浏览器。你同意并使用 AI 后，必要的岗位、档案或聊天内容会发给 DeepSeek；Key 用于请求鉴权。OCR 另需百度授权。本机同步是可选高级功能，独立服务不随此包提供。[隐私说明](PRIVACY.md)。

目前主要适配猎聘电脑网页；网页结构变化、登录失效和未知消息可能需要人工处理。外部联网补充取证当前暂停。真实招聘页面的完整覆盖和当前模型质量仍需持续验收。
