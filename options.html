DeepSeek API Key

用于生成话术 / 评分 / 画像 / 总结。仅存本地浏览器。申请：platform.deepseek.com

联网取证测试

当前 DeepSeek Responses API 不支持内置联网搜索。已暂停无效搜索请求，不消耗搜索测试 Token；岗位资料分析照常进行，外部交通、配套等信息保留待确认。


    

    
百度 OCR（图片转文字）

      
用于「截图 JD → 图片转文字」。百度智能云开通「文字识别」后获取。仅本地保存。

      

      

    


    
外部 AI 与隐私

      
岗位记录、聊天分析、个人档案、设置和 API Key 默认保存在本地浏览器。扩展默认不外发数据；启用后，相关功能会把必要的个人档案、JD、聊天文本或所选截图发送给对应服务处理。

      
      
    


    
个人能力档案

      
越具体，生成越对口。建议含：技术栈/核心技能、学历、2-3 个代表性项目或亮点、期望方向。

      
    


    
打招呼语 Prompt（高级）

      
自定义生成「打招呼语」的系统提示词。可增删要点、调整语气与长度要求；结尾需保持输出 JSON（含 matchPoints / greeting / keywords）。留空则使用默认提示。

      
    


    
文档导入（补充个人档案）

      
支持 .txt / .csv / .md / 制表符文本（如从 Excel 复制后粘贴）。真正的 .xls 二进制请用 Excel「另存为 CSV」再导入；下方粘贴区可直接粘贴表格文本（每行一条，Tab 或逗号分隔）。导入内容会作为补充条目追加到档案。

      

      
      
      

    


    
自动备份

      
每 5 分钟把求职数据备份为 JSON，并覆盖当天文件。API Key 会脱敏，百度临时 Token 和上次备份不会写入文件；导入时保留当前浏览器中的真实 Key。

      
      

    


    
手机访问 · 本机同步

      
将全部已收集岗位、聊天、档案和总结同步到这台电脑的个人服务，不上传到开发者服务器。模型 Key 不同步。首次同步前自动保留业务备份。
